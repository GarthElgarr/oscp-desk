# OSCP desk

Private methodology desk. On Kali:

```bash
git clone git@github.com:GarthElgarr/oscp-desk.git
cd oscp-desk
npm install
npm run dev
```

Open http://127.0.0.1:8080

Marks and notes stay in the browser. They are not in this repo.
The uploads folder on the machine is served by the desk. Put files there, not in git.
